# AYUSH Care / NOVA Clinical Frontend

This is the main React/Vite project. The dashboard is now the default screen.

## Integrated pages

- **Dashboard** — React dashboard shown at `/`
- **Clinical Case Taking** — existing React workflow, opened from the dashboard
- **Patient Timeline** — original `timeline.html`, copied into `public/pages/timeline.html`
- **Patient Report** — original `report.html`, copied into `public/pages/report.html`

The original files that were outside the main project have also been copied into this project root so the project is self-contained.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL and the dashboard will be shown first.
